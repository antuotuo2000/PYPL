先说结论：我认为 PayPal 是一家有真实竞争力、现金流不错，但正处于竞争压力和业务转型期的公司。

它现在最大的投资吸引力不是高速增长，而是：

  • 已经形成全球规模的支付网络。
  • 估值处于相对便宜的区间。
  • Venmo、Braintree 有一定增长潜力。
  • 股票回购力度较大。

但它也有一个非常重要的问题：PayPal 的支付规模还在增长，但核心品牌支付业务的竞争力并没有同步增强。

这决定了它究竟是被市场错杀，还是一家逐渐失去竞争优势的成熟公司。

一、公司究竟靠什么赚钱？

PayPal 并不是单纯的电子钱包，而是连接消费者、商户和金融机构的支付平台。

它主要拥有以下业务：

1. PayPal 品牌支付

  • 用户网上购物时使用 PayPal 付款。
  • 向商户收取交易手续费。
  • 这是品牌认知和消费者网络的重要基础。

2. Venmo

  • 美国消费者之间转账。
  • 商户付款、银行卡及金融服务。
  • 有机会从社交支付工具成长为综合金融平台。

3. Braintree

  • 为大型互联网平台提供后台支付处理。
  • 帮助商户处理信用卡和数字支付。
  • 交易规模大，但利润率和收费能力需要关注。

4. BNPL 先买后付

  • 用户分期消费。
  • 通过商户手续费和相关金融服务获利。
  • 增加用户场景，但也带来信用风险。

核心商业模式：

消费者付款 → PayPal 处理交易 → 商户支付手续费 → PayPal 获得收入。

它的核心资产不是软件本身，而是支付网络、商户接入、消费者账户和风控系统。

1. 收入增长：不够理想

这里有一个值得警惕的现象：

  • 支付额增长6%。
  • 收入只增长2%。
  • 净利润下降14%。

这说明 PayPal 虽然处理了更多交易，但没有充分将交易规模转化为利润。

这可能涉及交易结构、商户费率、营销补贴以及费用增长。

2. 最值得关注：核心品牌支付业务

2026年第三季度的业务情况：

  • Braintree 收入增加约2.7亿美元。
  • Venmo 收入增加约1亿美元。
  • PayPal 品牌支付相关收入减少约2.4亿美元。

品牌结账业务的交易量增长仍然有限，第三季度同比仅增长约1%（剔除汇率影响）。

这非常重要。

因为 PayPal 最有价值的资产之一就是消费者主动选择 PayPal 结账的能力。

如果消费者越来越习惯 Apple Pay、银行卡直接支付，那么 PayPal 的品牌价值可能逐渐被削弱。

3. 自由现金流：值得肯定

第三季度：

  • 经营现金流：15.92亿美元。
  • 自由现金流：14.31亿美元。
  • 调整后自由现金流：20.47亿美元。

需要注意，调整后自由现金流剔除了 BNPL 应收款出售和回款的时间差影响，不能直接当成普通自由现金流。

PayPal 仍然具备较强的现金创造能力，这是价值投资者值得关注的地方。

4. 股票回购：一个积极信号

2026年第三季度，公司回购了约28百万股股票，花费15亿美元。

过去12个月回购约1.17亿股，股数同比下降约8.8%。

这意味着：

  • 每股收益有机会得到提升。
  • 股东能够分享公司回购带来的权益比例增长。
  • 但回购不能代替主营业务增长。

如果公司股价低于内在价值，回购是好事；如果业务竞争力持续下降，回购也不能解决根本问题。

五、未来3–5年增长逻辑

我认为 PayPal 有三个值得观察的增长引擎。

第一：Venmo 商业化

Venmo 在美国拥有较强的年轻消费者基础。如果能够将社交转账用户转化为消费支付用户，商业价值有望提高。

(重要增长机会)

第二：Braintree 全球商户支付

大型互联网公司、订阅服务和电商平台需要稳定的支付基础设施。支付规模增长有望带来收入增长，但必须关注利润率。

第三：品牌结账业务复苏

如果 PayPal 能够改善结账体验、提升转化率，并重新获得商户和消费者的偏好，盈利能力可能出现改善。

(最关键的验证指标)

我特别关注第三点。

因为 Venmo 和 Braintree 增长，并不必然意味着 PayPal 核心品牌业务重新获得竞争优势。

PayPal 不能只成为一个低毛利率的支付通道。

如果它逐渐失去消费者主动选择的能力，长期估值可能从优质支付平台变成普通支付处理商。

这也是我不愿意直接给它20倍PE的原因。

八、如果我是价值投资者，会怎么配置？

我会将 PayPal 定义为：

成熟支付平台的困境反转投资，而不是高成长科技股。

我不会因为11倍PE就直接重仓。

我更希望看到：

  • 品牌结账业务恢复到5%以上增长。
  • 收入增速重新达到5%–8%。
  • GAAP营业利润恢复增长。
  • 自由现金流保持稳定增长。
  • Venmo 商业化持续提高盈利贡献。

其中前两项尤其重要。

如果这两项长期没有改善，就应该重新审视估值。

九、管理层与资本配置

PayPal 目前处于多年度转型阶段。

我认为需要重点考察管理层三个方面：

  • 能否提高品牌结账的转化率，而不只是通过降价吸引商户。
  • 能否让 Venmo 从用户规模转化为真实利润。
  • 能否在回购股票的同时，维持必要的技术和产品投入。

目前公司回购力度较大，这是积极信号，但第三季度GAAP营业利润仍下降8%，说明成本和经营效率尚未完全改善。

我暂时不会把管理层的转型承诺当作已经兑现的经营成果。

十二、最终投资结论

我的结论

值得观察，暂不急于买入

当前约59.48美元，估值看起来便宜，但业务增长质量还没有完全证明自己。

  • 低于48美元：我会认真考虑建仓。
  • 48–53美元：可以考虑分批买入。
  • 53–60美元：等待经营数据验证。
  • 65美元以上：需要重新计算安全边际。

我认为 PayPal 最值得投资的地方，是它拥有庞大的全球支付网络，而且市场目前只愿意给它较低的估值。

但它最大的隐患也是显而易见的：支付行业在增长，不代表 PayPal 一定能持续获得更多利润。

如果让我在 PayPal 和 Visa 之间选择，我会更认可 Visa 的商业模式质量；但如果只看困境反转和估值修复机会，PayPal 更值得研究。

对于3–5年价值投资，我更愿意等待品牌支付业务重新加速，再考虑提高仓位。

下一步我建议做一个更有价值的研究： 把 PYPL、V、MA、ADYEY、XYZ 放在同一张价值投资对比表里，比较过去5年收入增长、净利润率、自由现金流、ROIC、估值和未来5年预期回报，看看究竟哪家支付公司最值得长期持有。
